# Static SkillFolio

Static SkillFolio is a personal portfolio website for presenting Parashar Bhatt's professional profile, work experience, and project work. It highlights a professional summary, enterprise role history, professional development periods, core competencies, skills, certifications, and project cards with descriptions, categories, tools, and GitHub repository links.

The site is built as a single static HTML page and is intended to be published with GitHub Pages.
